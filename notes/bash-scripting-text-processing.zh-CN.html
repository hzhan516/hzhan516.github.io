Bash 脚本与文本处理：从零构建日志巡检脚本

以一个 SSH 日志巡检脚本为主线，逐步讲解重定向、管道、变量、条件与循环、正则表达式、grep、sed 和 awk。

目标与样例数据

这篇笔记从零写一个 log-audit.sh：读取 RHEL 风格的 SSH 安全日志（/var/log/secure），统计失败登录、按来源 IP 汇总、列出成功登录，并用退出码告诉调用者是否需要告警。每一节引入一个知识点，脚本随之迭代，最后给出完整版本。

先用 heredoc（here document，后面会讲）在当前目录生成一份样例日志。下文所有输出都来自这份数据的实际运行结果。

mkdir -p ~/log-audit && cd ~/log-audit
cat > sample-secure.log <<'EOF'
Nov  5 08:01:12 servera sshd[1201]: Failed password for root from 192.168.1.50 port 50122 ssh2
Nov  5 08:01:15 servera sshd[1201]: Failed password for root from 192.168.1.50 port 50122 ssh2
Nov  5 08:02:03 servera sshd[1210]: Accepted password for student from 192.168.1.10 port 50200 ssh2
Nov  5 08:03:44 servera sshd[1222]: Failed password for invalid user admin from 203.0.113.7 port 41000 ssh2
Nov  5 08:03:47 servera sshd[1222]: Failed password for invalid user admin from 203.0.113.7 port 41000 ssh2
Nov  5 08:03:50 servera sshd[1222]: Failed password for invalid user test from 203.0.113.7 port 41002 ssh2
Nov  5 08:05:10 servera sudo[1300]:  student : TTY=pts/0 ; PWD=/home/student ; USER=root ; COMMAND=/usr/bin/dnf update
Nov  5 08:06:21 servera sshd[1310]: Failed password for student from 192.168.1.10 port 50300 ssh2
Nov  5 08:06:30 servera sshd[1311]: Accepted publickey for operator from 10.0.0.5 port 52000 ssh2
Nov  5 08:07:02 servera sshd[1320]: Failed password for root from 192.168.1.50 port 50400 ssh2

最终脚本的输出是这样的：

$ ./log-audit.sh sample-secure.log

IP              FAILS  USERS                STATUS

$ echo $?
2
真实环境

在 RHEL 上读取 /var/log/secure 需要 root 权限，例如 sudo ./log-audit.sh /var/log/secure。练习时使用样例文件即可。

第一个脚本：shebang、执行权限与调试

Shell 脚本就是一个按顺序执行命令的文本文件。把重复的命令行操作写进脚本，可以减少手工输入错误，也便于复用和审查。

shebang

脚本第一行以 #! 开头，称为 shebang（也叫 hash-bang，# 读作 sharp 或 hash）。内核执行文件时读取这一行，用其中指定的解释器运行脚本：

#!/bin/bash
echo "log-audit: starting"
  • shebang 指定的解释器路径必须存在，否则会报 bad interpreter: No such file or directory。
  • 如果省略 shebang，结果取决于调用方式：从 Bash 中执行时，Bash 通常会用一个新的 Bash 子进程来运行它；其他程序调用时可能直接失败。所以始终写上 shebang。
  • 需要在不同系统间移植时，也可以写 #!/usr/bin/env bash，从 PATH 中查找 bash。

执行权限与运行方式

chmod +x log-audit.sh      # 添加执行权限
./log-audit.sh             # 在当前目录运行，需要执行权限，按 shebang 选解释器
bash log-audit.sh          # 显式调用 bash 解释，不需要执行权限，忽略 shebang
~/log-audit/log-audit.sh   # 使用绝对路径

Shell 只在 PATH 列出的目录中查找命令，当前目录默认不在其中，所以必须写 ./。如果把脚本放进 ~/bin 或 /usr/local/bin（都在 RHEL 的默认 PATH 里），就能直接输入脚本名运行。

./script 和 bash script 都会启动一个子进程运行脚本，脚本内设置的变量不会影响当前 shell。source script（或 . script）则在当前 shell 中执行，常用于加载配置。

调试与安全选项

命令 作用
bash -n script 只检查语法，不执行
bash -x script 或脚本中写 set -x 执行前把每条展开后的命令打印到标准错误，行首带 +
set +x 关闭跟踪
set -e 任何命令返回非零退出码时立即退出脚本
set -u 引用未定义的变量时报错退出
set -o pipefail 管道中任一命令失败，整个管道就返回失败 
$ bash -xc 'n=2; echo $((n*2))'
+ n=2
+ echo 4
4

log-audit.sh 在 shebang 后写 set -euo pipefail，让错误尽早暴露。代价是：确实可能“失败”的命令（例如 grep 没有匹配时返回 1）需要用 || true 显式放行。

I/O 通道与重定向

每个进程启动时至少有三个文件描述符（file descriptor，简称 fd）：

fd 名称 默认连接 用途
0 标准输入 stdin 键盘 只读
1 标准输出 stdout 终端 只写，输出正常结果
2 标准错误 stderr 终端 只写，输出错误和诊断信息
3+ 其他文件 无 由程序打开的文件

重定向改变这些通道的连接对象，让进程从文件读，或者写到文件，而不是终端。

写法 含义
> file stdout 覆盖写入文件
>> file stdout 追加到文件
2> file stderr 覆盖写入文件
2>/dev/null 丢弃 stderr
> file 2>&1 或 &> file stdout 和 stderr 都覆盖写入文件
>> file 2>&1 或 &>> file stdout 和 stderr 都追加到文件
< file 从文件读取 stdin
>&2 把这条命令的 stdout 送到 stderr

顺序很重要

Bash 从左到右处理重定向。2>&1 的意思是“让 fd 2 指向 fd 1 此刻指向的地方”：

$ ls /etc/hostname /nope > out.txt 2>&1; cat out.txt
ls: cannot access '/nope': No such file or directory
/etc/hostname

$ ls /etc/hostname /nope 2>&1 > out.txt; echo '--file:'; cat out.txt
ls: cannot access '/nope': No such file or directory
--file:
/etc/hostname

第一条先把 stdout 指向文件，再让 stderr 跟过去，所以两者都进了文件。第二条先让 stderr 指向 stdout 当时的位置（终端），之后才把 stdout 改到文件，所以错误仍然显示在终端上。

脚本中的错误信息

除非命令本身报错，脚本里 echo 的内容都走 stdout。用法说明和错误提示应该写到 stderr，这样用户把报告重定向到文件时，错误不会混进报告，也不会被管道下游当成数据：

usage() {
    echo "Usage: $(basename "$0") LOGFILE..." >&2
    exit 1
}

heredoc

<<'EOF' 到单独一行的 EOF 之间的文本会作为命令的 stdin，适合生成文件或多行输入。分隔符加了引号时，正文中的 $变量 不会展开；不加引号则会展开：

$ cat <<EOF
user: $USER-ish
EOF
user: doyle-ish

另一种形式 <<< 叫 here string，把一个字符串作为 stdin，脚本里用它把变量内容交给 awk 或 wc：wc -l <<< "$failed"。

管道、tee 与 xargs

管道符 | 把左边命令的 stdout 接到右边命令的 stdin。多个管道串起来时，数据依次流过每个命令，每一步只做一件事：

$ awk '/Failed/{print $11}' sample-secure.log | sort | uniq -c | sort -rn
      3 192.168.1.50
      2 admin
      1 test
      1 192.168.1.10

（结果里混进了 admin 和 test，这是字段错位，sed 一节会解决。）

  • 重定向把数据送进或取出文件，管道把数据送给另一个进程。
  • 管道只连接 stdout，stderr 默认不进入管道，需要时写 2>&1 | 或 |&。
  • 在同一条命令上，重定向先于管道生效。ls /etc/hostname > out.txt | wc -l 输出 0，因为 stdout 已经被重定向到文件，管道里什么都没有。

tee：既保存又继续传递

tee 像水管的三通，把 stdin 同时写到文件和 stdout。保存报告的同时还能在屏幕上查看：

$ ./log-audit.sh sample-secure.log 2>&1 | tee report.txt | tail -1
2 source(s) reached the threshold

tee -a 表示追加。一个常见用法是 echo "line" | sudo tee -a /etc/some.conf，因为 sudo echo ... >> file 中的重定向由当前用户的 shell 执行，没有 root 权限。

xargs：把 stdin 变成命令行参数

有些命令只接受参数，不读 stdin（如 rm、ls、ssh-copy-id）。xargs 把 stdin 中的内容转成参数：

find /etc -maxdepth 1 -name 'host*' 2>/dev/null | xargs ls -ld
printf 'a\nb\n' | xargs -I {} echo 'host={}'     # -I 指定占位符，每行执行一次
awk '{print $1}' hosts.list | xargs -I {} ssh-copy-id root@{}

注意 find ... | ls -l 是常见错误：ls 不读 stdin，只会列出当前目录。文件名可能含空格时，用 find -print0 | xargs -0。

变量、引用与环境

赋值与引用

变量名可以包含大小写字母、数字和下划线，不能以数字开头。等号两边不能有空格：

threshold=3                # 正确
threshold = 3              # 错误：会把 threshold 当成命令执行
echo "$threshold"          # 取值
echo "${threshold}rd"      # 花括号界定变量名
today=$(date +%F)          # 命令替换：把命令输出赋给变量
threshold=${THRESHOLD:-3}  # THRESHOLD 未设置或为空时用默认值 3

set 列出当前 shell 的所有变量和函数，unset name 删除变量。

引号

部分字符对 shell 有特殊含义（$、空格、*、;、| 等）。三种方式可以取消特殊含义：

方式 效果
反斜杠 \ 只转义紧跟的一个字符
单引号 '...' 全部按字面处理，不展开任何东西
双引号 "..." 保留空格，但仍展开 $变量、$(命令) 和 `命令` 
$ name=world; echo 'single: $name' "double: $name" escaped: \$name
single: $name double: world escaped: $name

经验规则：变量展开一律加双引号（"$file"），否则值中的空格会把它拆成多个参数；正则表达式和 awk 程序用单引号，避免 shell 先处理其中的 $ 和 *。

shell 变量与环境变量

普通变量只属于当前 shell。export 把它变成环境变量，之后启动的子进程（包括脚本）才能看到：

$ FOO=shell; bash -c 'echo child sees: [$FOO]'
child sees: []
$ export FOO; bash -c 'echo child sees: [$FOO]'
child sees: [shell]
$ export -n FOO      # 取消导出，FOO 变回普通 shell 变量，值保留
$ unset FOO          # 彻底删除
  • env 列出环境变量，set 列出全部变量。
  • VAR=value command 只为这一条命令设置环境变量。log-audit.sh 用这种方式接受配置：THRESHOLD=5 ./log-audit.sh sample-secure.log。
  • PATH 是最重要的环境变量，决定 shell 去哪些目录查找命令。HISTFILE、HISTFILESIZE、HISTTIMEFORMAT="%F %T " 等变量调整 history 的行为（格式符与 date 相同）。

启动文件

Bash 启动时读取哪些文件，取决于启动方式：

文件 范围 何时读取
/etc/profile、/etc/profile.d/*.sh 所有用户 登录 shell
~/.bash_profile 当前用户 登录 shell（RHEL 默认会再加载 ~/.bashrc）
~/.bashrc 当前用户 交互式非登录 shell，例如图形终端中新开的窗口
/etc/bashrc 所有用户 由 ~/.bashrc 加载

非交互式运行的脚本不会读取这些文件，它只继承父进程导出的环境变量。所以脚本不能依赖你在 ~/.bashrc 里定义的变量或函数，需要的值应该在脚本内设置或通过环境变量传入。修改启动文件后，用 source ~/.bashrc 在当前 shell 生效。

参数、退出码与 exec

位置参数

变量 含义
$0 脚本名（调用时使用的路径）
$1 … $9、${10} 第 1 到第 N 个参数
$# 参数个数
"$@" 全部参数，每个参数保持独立
"$*" 全部参数合成一个字符串，用空格连接
$? 上一条命令的退出码
$$ 当前 shell 的 PID

"$@" 和 "$*" 的差别在参数含空格时才明显：

#!/bin/bash
# args.sh
echo "\$# = $#"
for a in "$@"; do echo "  \"\$@\" -> [$a]"; done
for a in "$*"; do echo "  \"\$*\" -> [$a]"; done
for a in $*;   do echo "  \$*   -> [$a]"; done

$ ./args.sh 'web 01' db
$# = 2
  "$@" -> [web 01]
  "$@" -> [db]
  "$*" -> [web 01 db]
  $*   -> [web]
  $*   -> [01]
  $*   -> [db]

遍历参数时几乎总是用 "$@"。不加引号的 $*（以及 $@）会按空格再拆一次。log-audit.sh 用 "$@" 把所有日志文件原样交给 grep。

退出码

每个命令结束时返回 0 到 255 的退出码：0 表示成功，非零表示失败，不同的非零值可以区分不同错误。父进程从 $? 读取它。脚本用 exit N 提前结束并返回 N；不写 exit 时，返回最后一条命令的退出码。

$ bash -c 'false; echo rc=$?; exit 7'; echo outer=$?
rc=1
outer=7

log-audit.sh 的约定：0 正常，1 用法或输入错误，2 有来源达到告警阈值。这样 cron 或监控系统不用解析文本，就能判断结果。

注意 grep 的退出码：有匹配返回 0，没有匹配返回 1，出错返回 2。在 set -e 下，“没有匹配”也会终止脚本，所以要写 grep ... || true。

exec

exec 有两种用法：

  1. exec 命令：用该命令替换当前 shell 进程，PID 不变，后面的脚本内容不会再执行。常用于包装脚本的最后一步，例如 exec java -jar app.jar "$@"。
  2. exec 只带重定向：改变当前 shell 自己的文件描述符，对之后的所有命令生效。
#!/bin/bash
echo "before exec"
exec echo "exec replaced the shell"
echo "never printed"

log-audit.sh 用第二种实现 OUTPUT=file：之后所有 stdout 都写进文件，而错误信息仍然显示在终端上。

if [ -n "${OUTPUT:-}" ]; then
    exec > "$OUTPUT"
fi

测试与条件判断

test 表达式 和 [ 表达式 ] 是同一个命令，测试结果通过退出码返回：成立为 0，不成立为 1。[ 是命令名，所以两侧必须有空格。

$ x=5; [ $x -gt 3 ]; echo $?; [ $x -eq 3 ]; echo $?
0
1

常用测试

数值比较 字符串 文件
-eq 等于 = 或 == 相等 -e 存在
-ne 不等于 != 不等 -f 是普通文件
-gt 大于 -z 长度为零 -d 是目录
-ge 大于等于 -n 长度非零 -r / -w / -x 可读/可写/可执行
-lt 小于 -s 大小非零
-le 小于等于 -L 是符号链接

! 取反，&& / || 组合多个测试：[ -f "$f" ] && [ -r "$f" ]。

[[ ]] 与 (( ))

  • [[ ... ]] 是 Bash 关键字。变量不加引号也不会被拆分，支持通配符匹配 [[ $host == server* ]] 和正则匹配 [[ $n =~ ^[0-9]+$ ]]。
  • (( ... )) 做整数运算和比较，里面的变量不需要 $：(( fails >= limit ))。
  • $(( ... )) 返回运算结果：
$ a=10; echo $(( a + 1 )) $(( a / 3 )) $(( a % 3 )) $(( a * 3 )) $(( a ** 2 ))
11 3 1 30 100

Bash 只支持整数，10/3 得 3。需要小数时用 awk 'BEGIN{printf "%.2f\n", 10/3}' 或 bc。

if / elif / else

if (( fails >= limit )); then
    status=ALERT
elif (( fails > 0 )); then
    status=WARN
else
    status=OK
fi

Bash 按顺序测试条件，执行第一个成立的分支后跳过其余部分；都不成立时执行 else。if 后面可以是任何命令，不只是 [ ]：if grep -q root "$file"; then ...。

简单的分支可以用 && / || 简写：[ $# -ge 1 ] || usage。

脚本中的输入校验

[ $# -ge 1 ] || usage
threshold=${THRESHOLD:-3}
[[ $threshold =~ ^[0-9]+$ ]] || { echo "error: THRESHOLD must be a number" >&2; exit 1; }

循环

for

for file in "$@"; do              # 遍历参数
    if [ ! -r "$file" ]; then
        echo "error: cannot read $file" >&2
        exit 1
    fi
done

for i in $(seq 2 2 8); do ...     # 2 4 6 8：起始、步长、结束
for i in {1..5}; do ...           # 花括号展开
for ((i=1; i<=3; i++)); do ...    # C 风格

按行读取文件：用 while read

for line in $(cat file) 是常见错误，它按空白拆分，而不是按行：

$ printf 'web 01\ndb\n' > hosts.txt
$ for h in $(cat hosts.txt); do echo "[$h]"; done
[web]
[01]
[db]
$ while read -r h; do echo "[$h]"; done < hosts.txt
[web 01]
[db]

read -r 禁止反斜杠转义。read 还可以一次读多个字段，最后一个变量接收剩余部分。脚本的“成功登录”部分就用了这种写法：

awk '{ print $9, $11, $7 }' <<< "$accepted" | sort | uniq -c |
while read -r count user ip method; do
    printf '%-10s from %-15s via %-9s x%d\n' "$user" "$ip" "$method" "$count"
done

管道右边的 while 运行在子 shell 中，循环里设置的变量在循环结束后不可见。需要保留结果时，改用 done < file 或 done < <(command)。

until 条件; do ...; done 在条件成立前一直循环。break 跳出循环，continue 进入下一轮。

正则表达式与 grep

正则表达式是一套描述文本模式的语言，grep、sed、awk、vim、less 以及 Python、Perl 等都使用它。Linux 工具里有两种语法：

  • BRE（基本正则）：grep、sed 的默认语法。?、+、{}、()、| 需要写成 \?、\+、\{\}、\(\)、\| 才有特殊含义。
  • ERE（扩展正则）：grep -E、sed -E、awk 使用，这些符号直接生效，写起来更清楚。
$ printf 'catcat\ncat\n' | grep 'c\(at\)\{2\}'      # BRE
catcat
$ printf 'catcat\ncat\n' | grep -E '(cat){2}'       # ERE，等价
catcat

元字符

写法 含义 例子
. 任意单个字符 c.t 匹配 cat、c5t
[abc] / [^abc] 集合中的一个字符 / 集合外的一个字符 c[aou]t 只匹配 cat、cot、cut
^ / $ 行首 / 行尾 ^cat$ 整行只有 cat
* 前一项 0 次或多次 c.*t 以 c 开头、t 结尾（不要写成 c*t）
+ 前一项 1 次或多次（ERE） [0-9]+
? 前一项 0 或 1 次（ERE） colou?r
{n} {n,} {,m} {n,m} 前一项重复次数（ERE） c.{2}t 匹配 coat
(a\|b) 分组与选择（ERE） (admin\|test)
\b / \B 词边界 / 非词边界 \broot\b
\< / \> 词首 / 词尾 \<cat
\w / \W 词字符 [_[:alnum:]] / 非词字符
\s / \S 空白 / 非空白

POSIX 字符类要写在方括号里，例如 [[:digit:]]+：

类 含义
[:alnum:] 字母和数字
[:alpha:] 字母
[:digit:] 数字 0-9
[:xdigit:] 十六进制数字
[:lower:] / [:upper:] 小写 / 大写字母
[:blank:] 空格和制表符
[:space:] 所有空白字符，包括换行、回车、垂直制表符
[:punct:] 标点符号
[:print:] / [:graph:] 可打印字符（含空格）/ 可见字符（不含空格）
[:cntrl:] 控制字符

完整说明见 man 7 regex。

grep 常用选项

选项 作用
-i 忽略大小写
-v 反向，只显示不匹配的行
-c 只输出匹配行数
-n 显示行号
-o 只输出匹配到的部分
-w 整词匹配
-q 不输出，只返回退出码，适合放在 if 中
-l 只列出包含匹配的文件名

sed 进阶

sed（stream editor）逐行读取输入，对每一行执行一组命令，再把结果输出。它适合做替换、删除、插入和提取这类按规则批量编辑的工作，也适合在脚本里修改配置文件。

执行模型

  1. 读入一行，去掉换行符，放进模式空间（pattern space）。
  2. 依次执行脚本中地址匹配的命令。
  3. 打印模式空间（除非使用了 -n），然后清空，读下一行。

另外还有一个保持空间（hold space），在行与行之间保留数据，初始为空。

基本形式：sed [选项] '地址命令' 文件。

选项 作用
-n 不自动打印，只输出 p 命令打印的内容
-E 使用 ERE
-e 脚本 添加一段脚本，可多次使用
-f 文件 从文件读取 sed 脚本
-i[后缀] 直接修改文件；带后缀时先备份，例如 -i.bak

地址

地址 匹配
3 第 3 行
$ 最后一行
2,5 第 2 到 5 行
/re/ 匹配正则的行
/re1/,/re2/ 从匹配 re1 的行到下一个匹配 re2 的行
1~4 从第 1 行开始每 4 行一次（GNU 扩展）
addr! 不匹配该地址的行

替换命令 s

s/正则/替换/标志。分隔符可以换成任意字符，路径里有 / 时用 # 或 | 更易读：s#/usr/bin/#BIN:#。

标志 作用
g 替换行内所有匹配，默认只替换第一个
N（数字） 只替换第 N 个匹配
I 忽略大小写（GNU）
p 发生替换时打印该行，通常配合 -n
w 文件 发生替换时把该行写入文件

替换部分中，& 代表整个匹配，\1…\9 代表分组（BRE 里是 \(\)，ERE 里是 ()）：

保持空间

命令 作用
h / H 模式空间复制 / 追加到保持空间
g / G 保持空间复制 / 追加到模式空间
x 交换两个空间

反转行序（等同于 tac）：

$ printf 'a\nb\nc\n' | sed -n '1!G;h;$p'
c
b
a

逐行看：第 1 行 a 跳过 G，h 存入保持空间。第 2 行 G 把保持空间追加进来得到 b\na，再存回去。到最后一行，模式空间是 c\nb\na，用 $p 打印。

把空行分隔的段落合并成一行：

$ printf 'para1 a\npara1 b\n\npara2 a\npara2 b\n' | sed -n '/./{H;$!d};x;s/\n/ /g;s/^ //;/./p'
para1 a para1 b
para2 a para2 b

非空行用 H 累积到保持空间；不是最后一行时 d 结束本轮。遇到空行或最后一行时，x 把累积的段落换出来，把换行替换为空格，再打印。

awk 进阶

awk 把输入看成由记录（默认一行）组成，每条记录又拆成字段（默认按连续空白拆分）。awk 程序由 模式 { 动作 } 组成，对每条记录检查模式，匹配时执行动作。它适合按列提取、过滤、统计和格式化报告。

字段与内置变量

变量 含义
$0 整条记录
$1…$N 第 N 个字段；$NF 是最后一个，$(NF-1) 是倒数第二个
NF 当前记录的字段数
NR 已读取的记录总数（跨文件累计）
FNR 当前文件内的记录号
FS / OFS 输入 / 输出字段分隔符，-F 设置 FS
RS / ORS 输入 / 输出记录分隔符
FILENAME 当前文件名 
$ awk '{print $1, $2, $3}' sample-secure.log | head -2
Nov 5 08:01:12
Nov 5 08:01:15
$ awk -F: 'BEGIN{OFS=" -> "} NR<=2 {print $1, $6}' /etc/passwd
root -> /root
bin -> /bin
$ awk 'END{print NR}' sample-secure.log
10

第一个例子里 Nov 5 中的两个空格变成了一个，因为默认 FS 把连续空白当作一个分隔符，print 再用 OFS（一个空格）连接字段。cut -d' ' 则把每个空格都当分隔符，处理这种日志容易出错。

模式

模式 例子
正则 /Accepted/
字段匹配 $5 ~ /^sudo/，$6 !~ /Failed/
比较 $3 >= 1000，$6 == "Failed"
组合 /Failed/ && /root/，!/sshd/
范围 NR==2, NR==4
BEGIN / END 读取输入前 / 全部读完后执行一次 
$ awk '/Accepted/ {print $9, $11}' sample-secure.log
student 192.168.1.10
operator 10.0.0.5
$ awk '$5 ~ /^sudo/ {print $6, $NF}' sample-secure.log
student update
$ awk '/Failed/ && /root/ {n++} END {print n+0}' sample-secure.log
3
$ awk -F: '$3 >= 1000 && $3 < 60000 {print $1, $7}' /etc/passwd   # 普通用户

n+0 保证没有匹配时输出 0 而不是空字符串。

变量、printf 与 -v

awk 变量无需声明，未赋值时数值为 0、字符串为空。-v 把 shell 的值传进 awk，这比把 $var 拼进单引号程序安全：

$ awk -v ip=203.0.113.7 '$0 ~ ip {n++} END{print ip, n}' sample-secure.log
203.0.113.7 3
$ awk '/Failed/ {f++} /Accepted/ {a++} END {printf "failed=%d accepted=%d rate=%.1f%%\n", f, a, f*100/(f+a)}' sample-secure.log
failed=7 accepted=2 rate=77.8%

printf 的格式与 C 相同：%s 字符串、%d 整数、%.1f 小数、%-15s 左对齐宽 15、%5d 右对齐宽 5、%% 输出百分号。printf 不会自动换行。

关联数组

awk 的数组以字符串为下标，适合计数和分组：

$ awk '/Failed/ {c[$(NF-3)]++} END {for (k in c) printf "%-15s %d\n", k, c[k]}' sample-secure.log | sort -k2,2nr
192.168.1.50    3
203.0.113.7     3
192.168.1.10    1
$ awk '{split($3, t, ":"); h[t[1]":"t[2]]++} END{for(k in h) print k, h[k]}' sample-secure.log | sort
08:01 2
08:02 1
08:03 3
08:05 1
08:06 2
08:07 1
  • 第一个例子用 $(NF-3) 从行尾倒数取 IP，不受 invalid user 影响。这是解决字段错位的另一种方法。
  • for (k in a) 的遍历顺序不确定，需要稳定顺序时交给 sort。
  • (k in a) 判断键是否存在，且不会创建该键；delete a[k] 删除元素。
  • 多维下标 seen[ip, user] 实际上用 SUBSEP 把两个值拼成一个键。!seen[key]++ 是经典的去重写法：第一次出现时为真。

多文件处理：NR==FNR

读第一个文件时 NR 等于 FNR，借此先把查找表载入数组，再处理第二个文件。这相当于两个文件之间的 join：

$ printf '192.168.1.50 lab-gateway\n203.0.113.7 external-scanner\n' > known-hosts.txt
$ awk 'NR==FNR {name[$1]=$2; next}
       /Failed/ {ip=$(NF-3); print ip, (ip in name ? name[ip] : "unknown")}' \
      known-hosts.txt sample-secure.log | sort | uniq -c
      1 192.168.1.10 unknown
      3 192.168.1.50 lab-gateway
      3 203.0.113.7 external-scanner

next 立即开始处理下一条记录，跳过后面的规则。

改变记录分隔符

RS="" 进入段落模式，以空行分隔记录。配合 FS="\n"，每一行就是一个字段：

$ printf 'name: a\nage: 1\n\nname: b\nage: 2\n' | awk 'BEGIN{RS=""; FS="\n"} {print NR": "$1" / "$2}'
1: name: a / age: 1
2: name: b / age: 2

getline

getline 主动读取输入，常用于 BEGIN 块中读取其他文件或命令输出：

awk 'BEGIN { while ((getline line < "known-hosts.txt") > 0) n++; print n }'   # 输出 2
awk 'BEGIN { "date +%Y" | getline y; close("date +%Y"); print "year:", y }'

getline 成功返回 1、到达结尾返回 0、出错返回 -1，所以循环条件写 > 0，避免文件不存在时死循环。用完命令或文件后调用 close()。大多数场景用 NR==FNR 更简单。

在脚本中：统计并格式化报告

report=$(awk -v limit="$threshold" '
    {
        ip = $11; user = $9
        fails[ip]++
        if (!seen[ip, user]++)
            users[ip] = users[ip] (users[ip] ? "," : "") user
    }
    END {
        for (ip in fails)
            printf "%-15s %5d  %-20s %s\n", ip, fails[ip], users[ip],
                   (fails[ip] >= limit ? "ALERT" : "ok")
    }' <<< "$failed" | sort -k2,2nr -k1,1)
  • -v limit= 把 shell 中的阈值传入 awk。
  • fails[ip]++ 按 IP 计数；seen[ip, user] 给每个 IP 的用户名去重，users[ip] 用逗号拼接。
  • awk 中把两个字符串并排写就是拼接；三元表达式 cond ? a : b 决定状态。
  • sort -k2,2nr -k1,1 先按第 2 列数值倒序，再按 IP 排序，保证输出稳定。

完整脚本

#!/bin/bash
# log-audit.sh - summarize SSH login activity from secure-style logs
set -euo pipefail

usage() {
    echo "Usage: $(basename "$0") LOGFILE..." >&2
    echo "Env:   THRESHOLD=N (default 3)  OUTPUT=FILE (write report to FILE)" >&2
    exit 1
}

[ $# -ge 1 ] || usage
threshold=${THRESHOLD:-3}
[[ $threshold =~ ^[0-9]+$ ]] || { echo "error: THRESHOLD must be a number" >&2; exit 1; }

for file in "$@"; do
    if [ ! -r "$file" ]; then
        echo "error: cannot read $file" >&2
        exit 1
    fi
done

if [ -n "${OUTPUT:-}" ]; then
    exec > "$OUTPUT"
fi

failed=$(grep -hE 'sshd\[[0-9]+\]: Failed password' "$@" \
    | sed -E 's/ for invalid user / for /' || true)
accepted=$(grep -hE 'sshd\[[0-9]+\]: Accepted ' "$@" || true)

if [ -z "$failed" ]; then
    failed_total=0
else
    failed_total=$(wc -l <<< "$failed")
fi

echo "== SSH audit: $# file(s), threshold=$threshold =="
echo "Failed attempts: $failed_total"
echo
echo "-- Failed logins by source IP --"
printf '%-15s %5s  %-20s %s\n' "IP" "FAILS" "USERS" "STATUS"

report=""
if [ "$failed_total" -gt 0 ]; then
    report=$(awk -v limit="$threshold" '
        {
            ip = $11; user = $9
            fails[ip]++
            if (!seen[ip, user]++)
                users[ip] = users[ip] (users[ip] ? "," : "") user
        }
        END {
            for (ip in fails)
                printf "%-15s %5d  %-20s %s\n", ip, fails[ip], users[ip],
                       (fails[ip] >= limit ? "ALERT" : "ok")
        }' <<< "$failed" | sort -k2,2nr -k1,1)
    echo "$report"
fi

echo
echo "-- Successful logins --"
if [ -n "$accepted" ]; then
    awk '{ print $9, $11, $7 }' <<< "$accepted" | sort | uniq -c |
    while read -r count user ip method; do
        printf '%-10s from %-15s via %-9s x%d\n' "$user" "$ip" "$method" "$count"
    done
else
    echo "(none)"
fi

alerts=$(grep -c 'ALERT$' <<< "$report" || true)
if [ "$alerts" -gt 0 ]; then
    echo "$alerts source(s) reached the threshold" >&2
    exit 2
fi
exit 0
