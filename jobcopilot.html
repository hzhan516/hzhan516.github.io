Recruiter takeaway

Why this project matters.

JobCopilot shows how AI features become product workflows: upload a resume, parse structure, embed content, match jobs, explain recommendations, continue with a chat assistant, and track applications over time.

  • Resume pipeline

    Upload, parse, version, edit, download, and optimize resumes through backend workflows and AI service integration.

  • Semantic job matching

    PostgreSQL pgvector supports similarity recall, while AI ranking and feedback loops provide a path toward better recommendations.

  • Asynchronous AI processing

    RabbitMQ, worker processes, Redis buffers, and MinIO model artifacts separate long-running AI tasks from user-facing APIs.

  • Platform operations

    Docker Compose isolates frontend, backend, AI, data, cache, queue, and model-registry services behind a frontend gateway.

Architecture proof

Full-stack AI system, not a single demo endpoint.

The repository uses bounded backend modules, AI service abstractions, frontend routes, message queues, vector storage, and deployment docs as a coherent system.

Frontend and gateway

React 19, Vite 7, TypeScript, Nginx gateway, i18n, auth flows, resume pages, jobs, chat, tracking, and profile.

Backend domain

Java 21, Spring Boot 3.5, DDD, hexagonal architecture, Maven modules, REST controllers, and application services.

AI service and worker

Python 3.11, FastAPI, LiteLLM, embeddings, resume/job parsing, LightGBM ranking, RabbitMQ consumers, Redis, and MinIO.

Honest scope

JobCopilot is presented as a public portfolio project with a mature local/container architecture. The current local knowledge base does not claim verified production deployment or broad real-user ranking validation.
