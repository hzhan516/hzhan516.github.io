My Contributions

Connected chat, memory, and desktop workflows

As the primary developer, built the Go backend and React interface, integrated model providers and memory retrieval, and worked on testing and desktop packaging.

  • Local storage and retrieval

    Integrated SQLite/SQLCipher and local retrieval components to store conversations and retrieve relevant health information.

  • Three-layer conversation memory

    Implemented working, short-term, and long-term memory with vector and keyword search so earlier information can be recalled during later conversations.

  • Model integration and context management

    Integrated OpenAI-compatible APIs and local model providers with streaming responses and summary compression to manage conversation context.

  • Desktop testing and packaging

    Added memory and privacy workflow tests and fixed Windows library packaging and CI configuration to support repeatable builds.
